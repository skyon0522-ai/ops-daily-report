Method and sharing notes

Drain3 groups similar message text into templates. Each service has a separate miner. Baseline messages are processed first, followed by current messages. This comparison uses the final templates for both batches.

Settings: {'depth': 4, 'sim_th': 0.4, 'max_children': 1000, 'miner_scope': 'per_service', 'shared_pass_order': 'baseline_then_current'}. Severity comes from supported log headers. Unsupported lines remain visible as unknown-level messages.

Template grouping does not diagnose incidents or prove that a new pattern is anomalous. Templates can still contain sensitive text: review all report formats before sharing. No raw log excerpts are intentionally added.
